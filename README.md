# CEP Finder

Um buscador de CEP rápido e fácil, com integração via API. Digite o CEP e receba o endereço completo (logradouro, bairro, cidade e estado) em segundos.

🔗 **Demo:** [matt-cepfinder.vercel.app](https://matt-cepfinder.vercel.app)

## ✨ Funcionalidades

- Busca de endereço a partir do CEP
- Retorno de logradouro, bairro, cidade e UF
- Interface simples, rápida e responsiva

## 🚀 Tecnologias

- [Next.js](https://nextjs.org/) 16 (App Router)
- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) 4
- Deploy na [Vercel](https://vercel.com/)

## 🛠️ Scripts disponíveis

| Comando         | Descrição                          |
| --------------- | ----------------------------------- |
| `npm run dev`   | Inicia o servidor de desenvolvimento |
| `npm run build` | Gera a build de produção            |
| `npm run start` | Inicia o servidor em modo produção  |
